One step before the first effect: the maker needs an Anthropic API key.
1. Create a key at console.anthropic.com → API keys.
2. In the project folder make a text file named .anthropic.key and paste the key in it (nothing else).
3. Press Check again. The key stays on this computer and is never uploaded to GitHub.
